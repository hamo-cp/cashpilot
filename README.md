# CashPilot

تطبيق PWA لإدارة الدخل والمصروفات والديون والاستثمارات والميزانية، مع تخزين محلي في المتصفح.

## التشغيل

يجب تشغيل التطبيق عبر HTTP كي تعمل ES modules وService Worker:

```powershell
python -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## المصدر التنفيذي

- `index.html` و`style.css`: الواجهة الفعلية.
- `src/main.js`: نقطة الدخول الوحيدة.
- `src/core/`, `src/pages/`, `src/services/`, `src/storage/`, `src/ui/`, `src/charts/`: وحدات التطبيق.
- `vendor/chart.js-4.4.0/`: نسخة same-origin متحققة من مكتبة الرسوم مع ترخيصها وSHA-256.
- `files/`: أيقونات PWA فقط؛ يجب أن يبقى الأرشيف المتقاعد `cashpilot.zip` غائبًا عن شجرة الإصدار.
- `service-worker.js`: precache صريح للـimport graph الفعلي، ولا يخزن موارد cross-origin.
- `tests/`: اختبارات regression الأمنية والسلوكية.

لا توجد نسخة تنفيذية ثانية مدعومة. يجب نشر المصدر الفعّال بقائمة allowlist تستبعد الأرشيف المتقاعد، أو حذفه قبل النشر.

## الشبكة والخصوصية

البيانات المالية تبقى في `localStorage`. صفحة الاستثمارات تجلب أسعار سوق رقمية من مصادر عامة، وتتحقق من schema والأنواع والحدود قبل التخزين أو العرض. عند تعذر الشبكة يمكن استخدام cache صالح ومحدود العمر.

## النسخ الاحتياطية

الاستيراد يقبل صيغة CashPilot الرسمية الحالية أو الصيغة السابقة ذات المفاتيح الستة فقط. يجري التحقق من كل حقل قبل أي كتابة، وتحاول طبقة التخزين استعادة القيم السابقة عند فشل الكتابة؛ وإذا تعذرت الاستعادة يُعرض للمستخدم خطأ صريح. المفاتيح أو الحقول غير المعروفة تُرفض.

## التحقق

```powershell
npm test
```

يشمل ذلك اختبارات schema، منع XSS، rollback، بيانات السوق، تعديل الاشتراكات، حساب الميزانية والتدفق، اكتمال precache، وسلامة dependency المحلية.

### GitHub Actions CI

ملف `.github/workflows/ci.yml` يشغّل `npm test` على Ubuntu وWindows باستخدام Node.js 24، عند الدفع أو فتح Pull Request، ويمكن تشغيله يدويًا. لا توجد حزم npm مطلوبة لتشغيل الاختبارات.

مهمة متصفح منفصلة تشغّل `npm run test:browser` على Chrome بملف مستخدم وخادم محلي معزولين، وتشمل العربية والإنجليزية، الخصوصية، العمل دون اتصال، ومقاسات الهاتف. تحفظ السجلات وصور الاختبار في `browser-evidence` لمدة 7 أيام. هذه الفحوص لا تنشر التطبيق؛ يجب مراجعة نتيجة تشغيل Actions على commit المقصود قبل اعتباره ناجحًا.

لتشغيل اختبار المتصفح محليًا، شغّل `npm run serve:test` ومتصفح Chromium بملف مستخدم اختباري مستقل وCDP على localhost، ثم اضبط `CASHPILOT_CDP_PORT` وشغّل `npm run test:browser`. يستخدم الاختبار بيانات صناعية ويمسح تخزين أصل الاختبار؛ يجب أن يكون `CASHPILOT_BASE_URL` أصلًا محليًا معزولًا (الافتراضي `http://127.0.0.1:3000`).

### أيقونات PWA

الملفات الأربعة في `files/` مطابقة للمقاسين المعلنين `192x192` و`512x512`. نسختا `maskable` تستخدمان الشعار نفسه مع هامش يحفظه داخل [منطقة الأمان المحددة في معيار Web App Manifest](https://www.w3.org/TR/appmanifest/#icon-masks-and-safe-zone). تتحقق اختبارات الإصدار من أبعاد PNG الفعلية، ويتحقق اختبار المتصفح من فكّ ترميز الأيقونات وتحميلها أثناء الاتصال وبعد إعادة التحميل دون اتصال.

عند تغيير الأصول المخزنة للعمل دون اتصال، حدّث `CACHE_NAME` في `service-worker.js` لضمان إنشاء ذاكرة جديدة عند التحديث.
