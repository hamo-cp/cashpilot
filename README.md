# CashPilot Hybrid v1

هذه الحزمة تحتوي نسختين:

1. `index.html`
   - نسخة مدمجة تعمل مباشرة من الهاتف عند فتح الملف.
   - لا تعتمد على تحميل CSS/JS من مجلدات خارجية.
   - مناسبة للاختبار من Android عند ظهور مسار `content://`.

2. `src/`
   - الملفات المنظمة للتطوير لاحقًا.
   - CSS و JS مفصولان لتسهيل التعديل والرفع على GitHub.

## سبب هذه النسخة

في بعض متصفحات Android، فتح HTML من مدير الملفات عبر `content://` يمنع تحميل ملفات CSS و JavaScript module من مجلد `src/`.
لذلك ظهرت الصفحة كـ HTML خام. هذه النسخة تعالج ذلك بجعل `index.html` مدمجًا.


## Hotfix: budget input on mobile

تم إصلاح مشكلة اختفاء لوحة المفاتيح عند تحرير حقول الميزانية على الهاتف.

### السبب
كان المشروع يعيد `render()` كاملًا عند كل `resize`.
عند فتح لوحة المفاتيح في الهاتف يتغير ارتفاع الشاشة، فيُطلق المتصفح حدث `resize`، فيُعاد إنشاء حقل الإدخال ويفقد التركيز.

### الإصلاح
أصبح `resize` يعيد الرسم فقط إذا تغيّر **عرض** الشاشة، وليس الارتفاع فقط.


## Final Polished v1 — إصلاحات دقيقة

تم تنفيذ الإصلاحات التالية فقط:

- توحيد مفتاح التخزين بين `index.html` ونسخة `src`.
- نقل إصلاح لوحة مفاتيح الهاتف إلى `src/js/app.js`.
- إصلاح توليد التاريخ المحلي بدل الاعتماد على `toISOString`.
- تحسين تحقق الاستيراد على مستوى السجلات.
- إخفاء عناصر التحكم قبل إتمام أول تشغيل.
- تسجيل Service Worker فقط عند التشغيل من `http/https`.
- تحديث اسم كاش Service Worker لتجنب الكاش القديم.

لم يتم تغيير التصميم أو الألوان أو الرسوم أو تجربة الاستخدام الأساسية.
