# CashPilot

تطبيق PWA لإدارة الدخل والمصروفات والديون والاستثمارات والميزانية، مع تخزين محلي في المتصفح.

## التشغيل

يجب تشغيل التطبيق عبر HTTP كي تعمل ES modules وService Worker:

```powershell
python -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## المصدر التنفيذي

- `index.html` و`style.css`: الواجهة الفعلية.
- `src/main.js`: نقطة الدخول الوحيدة.
- `src/core/`, `src/pages/`, `src/services/`, `src/storage/`, `src/ui/`, `src/charts/`: وحدات التطبيق.
- `vendor/chart.js-4.4.0/`: نسخة same-origin متحققة من مكتبة الرسوم مع ترخيصها وSHA-256.
- `files/`: أيقونات PWA فقط؛ يجب أن يبقى الأرشيف المتقاعد `cashpilot.zip` غائبًا عن شجرة الإصدار.
- `service-worker.js`: precache صريح للـimport graph الفعلي، ولا يخزن موارد cross-origin.
- `tests/`: اختبارات regression الأمنية والسلوكية.

لا توجد نسخة تنفيذية ثانية مدعومة. يجب نشر المصدر الفعّال بقائمة allowlist تستبعد الأرشيف المتقاعد، أو حذفه قبل النشر.

## الشبكة والخصوصية

البيانات المالية تبقى في `localStorage`. صفحة الاستثمارات تجلب أسعار سوق رقمية من مصادر عامة، وتتحقق من schema والأنواع والحدود قبل التخزين أو العرض. عند تعذر الشبكة يمكن استخدام cache صالح ومحدود العمر.

## النسخ الاحتياطية

الاستيراد يقبل صيغة CashPilot الرسمية الحالية أو الصيغة السابقة ذات المفاتيح الستة فقط. يجري التحقق من كل حقل قبل أي كتابة، وتحاول طبقة التخزين استعادة القيم السابقة عند فشل الكتابة؛ وإذا تعذرت الاستعادة يُعرض للمستخدم خطأ صريح. المفاتيح أو الحقول غير المعروفة تُرفض.

## التحقق

```powershell
npm test
```

يشمل ذلك اختبارات schema، منع XSS، rollback، بيانات السوق، تعديل الاشتراكات، حساب الميزانية والتدفق، اكتمال precache، وسلامة dependency المحلية.
